# Codex 宿主适配卡

```text
HOST=codex
EXTERNAL_ENGINE=claude       # 内核自动取与宿主不同家族的一方；台账里的引擎状态名是 claude_external
```

所有 flow 命令带 `--host codex`。

## 把工单变成派发

| 工单字段 | 用法 |
|---|---|
| `agent` | 项目 `.codex/agents/` 里的命名角色（经济档是 `<角色>-economy`）。为空时看 `agent_fallback`：角色文件缺失或与合同正本不一致，改派通用子代理 |
| `step_id` | 子代理的任务名，原样填写——内核按它对账用量 |
| `prompt_inline` | 任务消息，原样填写，不追加背景说明 |

- 派发一律用**不继承主会话历史**的新子代理（不要分叉当前会话）：带着历史分叉出去的子代理会把主会话的上下文整个再付一遍。
- 当前会话还没加载到 setup 新装的命名角色时，同样改派通用子代理；任务文件开头写着角色合同的路径，子代理会先读它。
- 同一次 `next` 返回的多张 `dispatch` 工单并行派出，全部返回后再 `flow done`。子代理不嵌套派发、不调用 skill、不改 `state.json`。

## 后台外审

`exec` 工单：先执行工单里的 `command`（带 `--detach`），再执行 `flow wait <id>`，没等到就再执行一次。外审通过 `tools/external_review.py` 调 Claude Code CLI，工具面限制为只读。沙箱里后台进程活不过命令返回时，去掉 `--detach` 改为前台执行并把命令超时放到 30 分钟以上。沙箱不能联网时外审会失败，内核自动降级：先给一张通用子代理的同宿主盲审工单（台账记 `same_host_fallback`，评级封顶 B），那一步也交不出来才记为跳过。

## 向人提问与凭据

Codex 没有可用的钩子。停在检查点时把审阅包要点、各选项的后果和 `[<检查点 id> · <短码>]` 发给人，等人答复。

- 人在自己的终端执行 `flow decide …` 并当场输入短码：终端级凭据。
- 你代为执行 `flow decide … --quote "<人的原话>"`：自述级凭据，看板和报告附录会标出来。

## 禁读清单

没有读文件前的拦截。任务文件里写着禁读清单；内核在点收时扫描子代理的会话记录，命中会记入事件流并在看板标出。
