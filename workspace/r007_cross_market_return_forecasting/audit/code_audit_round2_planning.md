## 二、CA-ALL-R1-01 裁决：动态可预测键，无任意容忍率

### 2.1 裁决结果

审计建议的正确口径不是“全股票池每日零缺口”，也不是预先指定 90%、95% 或其他任意覆盖容忍率，而是：

1. 以每个方向、预测日、图快照和规格为单位，从图快照/特征映射与训练审计导出动态可预测键。
2. AS14 允许的无入边目标，以及 AS2 已登记的 complete-case 后样本不足或必要观测缺失，可以不进入动态可预测键，但必须逐键给出唯一、可重算的排除原因并汇总统计。
3. 一旦某个 `(方向, 预测日, 目标股票, 规格)` 被判为动态可预测，八个基础模型均不得额外丢失；均值与中位数集成只在同键八模型齐全时生成，最终十模型对该动态可预测键集合必须完全一致。
4. 三规格比较必须先分别审计各规格的动态键，再显式生成共同键；共同键收缩量和各原因必须披露，不得以静默 inner join 代替审计。
5. 全500股票池只作为机会集合和缺失率分母，不作为每个交易日必须全部预测的硬门禁。

### 2.2 coder 验收合同

- 必须输出逐键审计表，至少包含：`direction`、`prediction_date`、`snapshot_date`、`target_code`、`specification`、`graph_has_in_edges`、`feature_count`、`complete_case_nobs`、`min_required_nobs`、`eligibility_status`、`exclusion_reason`。
- `eligibility_status` 只能明确区分 `predictable` 与合法排除；合法排除原因至少拆分 `no_in_edges`、`complete_case_insufficient`、`required_observation_missing`，不得合并为不透明的 `other`。
- 对每个动态可预测基础键，必须存在且仅存在 OLS、LASSO、RIDGE、SVM、XGBoost、LGBM、Random Forest、AdaBoost、ensemble-avg、ensemble-med 十条输出；缺任一模型、重复键、模型间键不一致均硬失败。
- 必须输出以全股票池机会数为分母的逐日及全样本统计：无入边数/率、complete-case 样本不足数/率、必要观测缺失数/率、动态可预测数/率、实际十模型完整键数/率。
- 任一动态可预测键未产出完整十模型、存在未登记排除原因、整日动态可预测键为零、或三规格共同键不是由已审计集合显式求交，均硬失败。
- 禁止新增任意覆盖率容忍参数作为 pass 条件；覆盖率只作诊断，键级集合相等才是门禁。

结论：`CA-ALL-R1-01` 可按上述合同修复，不需要新增方法假设。

## 三、CA-ALL-R1-02 裁决：精确日期保留，行业子集明确降级

### 3.1 裁决结果

FIG3 必须拆成“可忠实实现的论文事实”和“因 D9 不可实现的论文事实”：

- 可忠实实现：必须为 `2021-10-21` 单独构建一次图，使用该日期之前的250个历史交易配对和 F4-F5/B4-B5 已登记公式、方向与滞后；不得从每10日更新序列选择最近锚点。
- 不可忠实实现：缺少美股行业分类时，不能重建“每行业最多25只”的254×235子集，也不能凭 A 股单边行业、股票顺序或全量 B1 节点倒推出该子集。
- 允许的替代交付：在精确日期上输出全量 B1 代理节点的带符号 t 统计量矩阵/热图，并显式标记为 `degraded/substitute`。该产物只能说明“精确日期的全量 B1 代理图”，不能命名或宣称为原 FIG3 完整复现。

新增实现假设：

- `AS27`：FIG3 以精确日期的全量 B1 代理图降级交付。
- 来源：`A5（CA-ALL-R1-02 补充 auto 裁决）`。
- 性质：`experimental-degraded`。
- 高亮等级：`major-auto`。
- 核心文本：论文事实仍是 2021-10-21、254×235 行业限额矩阵；实现只保留精确日期与 F4-F5 构图，行业子集因 D9 缺失不伪造，改交全量 B1 代理图。

### 3.2 coder 验收合同

- 必须存在 FIG3 专用的一次性构图入口或等价调用路径，输入锚点严格为 `2021-10-21`；不得调用“最近图快照”选择逻辑。
- 必须证明训练/回看数据全部早于图日期，并按既有 F4-F5/B4-B5 口径使用250个历史交易配对；图日期本身不得泄漏进训练窗。
- 必须输出机器可读 FIG3 口径清单，至少包含：
  - `paper_requested_date=2021-10-21`
  - `effective_graph_date=2021-10-21`
  - `used_nearest_update_anchor=false`
  - `paper_universe=industry_capped_254_us_x_235_cn`
  - `implemented_universe=full_b1_proxy`
  - `industry_limit_applied=false`
  - `missing_dependency=D9`
  - `reproduction_status=degraded/substitute`
  - `assumption_id=AS27`
  - 实际行列市场、节点数、节点有序清单及其 hash、训练日期范围、矩阵数据 hash
- 热图标题、文件旁注和工作簿 sheet 说明必须含“全量 B1 代理”“degraded/substitute”或等义的明确降级标签；不得出现“FIG3 complete reproduction”“原 FIG3 完整复现”等表述。
- 行列市场方向必须与 spec 登记一致：行=中国、列=美国；若内部矩阵以源×目标存储，输出前必须显式转置并在清单记录。
- 254×235 只能作为论文事实写入清单，不得作为替代图维度验收目标；替代图实际维度必须由当日 B1 代理节点清单重算。
- 若 `2021-10-21` 无法形成合法的250期历史配对，应硬失败并报告数据缺口，不得回退到邻近日期。

结论：原 FIG3 的行业限额矩阵仍不可完整复现；但精确日期的降级代理图有明确实现路径，因此该 issue 对下一轮编码不是 blocker。
