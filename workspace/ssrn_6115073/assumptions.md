### [AS15] Δβ 双区制显著性口径：频率适配 α=0.10 + 窄池回退梯度（planner 定向裁决 2026-07-11）
- 来源: A15（auto 裁决）→ m2 实测暴露频率迁移障碍后 planner 定向裁决修订
- 性质: method-adaptation（频率迁移）
- 裁决状态: 已裁决（原「5% 双系数」口径修订）
- 修订记录（保留存档）: 原口径「β⁺ 与 β⁻ 两系数均需 p<0.05（双侧 5%）方入选；行业惯例 5% 通行默认；状态 assumed；高亮 -」。m2 忠实实现后实测双系数联合显著对极稀少（hs300 10 只 / sz50 1 只 / zz500 21 只候选，详见 AS43），根因为频率迁移下月频训练观测仅约 144（双区制各 60-70）致 OLS 功效暴跌；据实验模式「方法论最标准 + 迁移 A 股最可落地」优先级修订为下述频率适配口径。
- 假设内容（裁决口径）:
  - **主口径（Tier 1，所有市场先按此跑）**：显著性阈值由 5% **频率适配上调至 α=0.10（双侧）**，保留「β⁺ 与 β⁻ 两系数均 p<0.10」的双系数结构 + 「按 |Δβ| 排序取头部」（AS9）；top_n=50 为头部规模上限（不足则全取，AS41），min_regime_obs=24 不变（AS41，非本次调整对象）。
  - **窄池回退（Tier 2，仅当某市场 Tier-1 候选数 < viability_floor≈15 时对该市场触发）**：同 α=0.10 但放宽为**单系数显著**（β⁺、β⁻ 至少一个 p<0.10），保留 |Δβ| 排序与 min_regime_obs=24；该市场结果标注为 degraded（窄池需放宽过滤一档）。
  - **诚实排除（若该市场 Tier-2 候选数仍 < 6）**：退出主分析，如实报告「方法在该窄池不迁移（月频功效不足）」（对齐 plan §九「方法迁移失效如实报告」），**不**用无显著性的纯 |Δβ| 强行凑数。
  - α 全市场统一取 0.10、回退由**结构性池规模阈值**触发（非按下游绩效逐市场调 α），杜绝调参式挑选；viability_floor/exclusion 阈由 coder 按实际候选数确认，边界情形回报 planner。
- 裁决依据:
  1. plan〇/四实验模式优先级 =「方法论最标准 + 迁移 A 股最可落地」，数值对齐豁免；
  2. **频率迁移标准做法**：原文 5%@日频（约 6000 观测/双区制各约 3000）与本案 α@月频（约 144 观测/双区制各 60-70）应求**统计行为等价而非阈值数值等价**——观测数降约 46×、β 标准误膨胀约 6-7×，机械沿用 5% 会让原本可检出的经济敏感度因功效不足被误剔，10% 为通行「边际显著」标准阈，属原则性适配而非凑数；
  3. 实测单系数显著率 β⁺≈8.9%/β⁻≈9.4%（＞5% 随机零假设）证明月频下确有真实非对称敏感信号被 5% 双系数过度剔除；双系数联合率 0.28%＜独立期望 0.84% 说明「两系数同显著」与 A 股月频数据结构负相关，窄池放宽为单系数比死守双系数更贴合方法「筛可靠 Δβ」的本意；
  4. **拒绝伪复制捷径**：不采「宏观月值前填到日频、把 n 灌回约 6000」——前填制造伪重复观测、虚增显著性（违反 OLS 独立性），才是真正的放水；在诚实月频下适配 α 才是严谨选择。
- 影响面: method

### [AS56] EW/MV 建仓 + 回测/换手/成本 + 指标算术年化口径 + R1 加粗方向
- 来源: coder 主动简化（落地 F1/F11/B5/B6/B7/AS3/AS11/AS5/AS22）
- 假设内容:
  - **EW（等权）**：每月 selected 资产 1/n 等权（`common.allocation_backtest.equal_weights`）。

### [AS58] 外部基准五模型实现（Index / HRP / HERC / NCO / OLMAR）
- 来源: coder 主动简化（落地 spec B8 外部基准；原文未给各基准实现细节 A11）
- 假设内容: 外部基准在**同候选池**（m2 sel.candidates）+ 同测试区间 + 同 tradeable 过滤下运行各自标准配置逻辑（`common.allocation_backtest` 通用引擎，供后续 allocation 案例复用）：

  - **HRP（López de Prado 2016）**：相关距离 `d=sqrt(0.5(1−corr))` single-linkage 层次聚类 + 准对角 + 递归二分（逆簇方差分配），逐月 ≤T 扩展窗协方差（`hrp_weights`/`hierarchical_panel`）。
  - **HERC（Raffinot 2018）**：同 HRP 树结构，簇内改用等风险贡献（风险平价）而非逆方差（`herc_weights`）；弱结构下与 HRP 接近。
  - **NCO（López de Prado 2019）**：相关距离 ward 层次聚类切 ≈sqrt(n) 簇，簇内长仓最小方差得簇组合、簇间对簇组合降维协方差再最小方差、合并为资产权重（`nco_weights`，exp_ret 保留接口用最小方差口径不消费）。
  - **OLMAR（Li & Hoi 2012）**：SMA 均值回归——预测价格相对 x̃=SMA(w)/p_t=**past/current**（持续上涨标的 x̃<1→减仓涨方，Mean **Reversion**），用 ≤T 最近 OLMAR_WINDOW_M=5 月价格相对估、被动激进更新 + 单纯形投影（ε=OLMAR_EPSILON_M=10，`olmar_weights`/`olmar_panel`）；在线学习需固定资产集传权重故用候选全集、**不逐月 tradeable 过滤**（基准标准实现），缺失收益月价格相对置 1（不变）、不可交易资产收益缺失在回测时贡献 0。
  - **CA-A01 订正（2026-07-11 code_audit）**：原 `olmar_weights` 实现 `x̃=cumprod(pr[::-1]).mean()`=**current/past** 方向写反成**动量**（加仓涨方），审计独立小例（A 持续涨→权重 A=1.0 动量行为）+ R1 里 OLMAR AStd 异常高（其它基准 3-5 倍）证实为此 bug 表征；已改为 `x̃=(1/cumprod(pr[::-1])).mean()`=**past/current** 标准 OLMAR 均值回归，函数签名与 simplex 投影不变。重跑后 OLMAR 波动回落正常（见下预期影响冒烟值）。
- 行业惯例依据: HRP/HERC/NCO/OLMAR 均有标准算法定义（原文只列名称未给参数，A11）；同候选池对比才公平隔离「配置方法」变量；OLMAR 在线特性决定其用固定池
- 影响面: method
- 影响 milestone: m6
- 影响指标: R1（外部基准列 Index/HRP/HERC/NCO/OLMAR）、§九.3 相对基准优势
